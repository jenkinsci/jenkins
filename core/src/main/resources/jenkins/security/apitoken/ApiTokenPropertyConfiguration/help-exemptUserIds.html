The IDs of the users whose API tokens are not restricted by the maximum lifetime, one ID per line. Use it for service accounts that cannot rotate their tokens yet.

This list is a migration aid, not a permanent state: plan to rotate the tokens of these accounts and to empty the list.

The exemption belongs to the ID, not to the person. If an account is deleted and its ID is used again, the new account inherits the exemption. An ID that is listed before its account exists is exempt for whoever creates that account, including a user who signs up by themselves.

The field warns about the IDs that Jenkins does not know yet. With an external security realm, users only appear after their first login, so the warning does not mean that the ID is wrong.

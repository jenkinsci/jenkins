By default, all Maven builds on the same agent share one local repository, usually ~/.m2/repository (or the location set in settings.xml).

If checked, this build uses its own local repository in the .repository directory of the workspace, by passing -Dmaven.repo.local=$WORKSPACE/.repository to Maven. This isolates the build from other builds on the same agent, for example SNAPSHOT artifacts installed by other jobs, or several Maven processes writing to the same repository at once.

It uses more disk space, and dependencies are downloaded again for each workspace. Wiping the workspace also deletes this repository.
